# Keep your queries

- **Query History** keeps every statement you run, per connection, newest first: search it, open a
  statement in an editor or run it again. Statements that set a password are kept with their strings
  masked, and the statements that apply changes from the grid are not kept.
- **Saved Queries** keeps named queries in folders: save the selection or the whole editor with the
  **Save Query** button of its title bar, then open or insert one, and import or export them as a
  JSON file. An editor opened from a saved query saves back to it.

Both live on this machine, in VS Code's storage for the extension.
